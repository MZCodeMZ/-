# Kigo Parent iOS App

A SwiftUI prototype for the Kigo parent experience. It includes a home dashboard, daily schedule, message inbox with conversation detail, and child profiles so caregivers can check in quickly.

## Running
1. Open the repo in Xcode 15 or newer on macOS.
2. In Xcode, choose **File → Open**, select `Package.swift`, and trust the project.
3. Set the run destination to an iOS 16+ simulator and press **Run**.

## Features
- **Home dashboard** with quick actions (check-in, running late, message teacher) and today's schedule + recent messages.
- **Schedule** list that highlights context and notes for each block of the day.
- **Messages** inbox with unread badges and conversation view per staff member.
- **Child profiles** detail cards with classroom, age, and health info.
